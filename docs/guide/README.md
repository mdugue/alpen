# Alpenpässe – Wissen

Alpenpässe ist eine Rennradkarte für die Urlaubsplanung in den Alpen. Diese
Seiten erklären, was die Karte zeigt, woher ihre Daten kommen, wie
Bewertungen und Status entstehen und wo ihre Grenzen liegen.

1. [So funktioniert die Karte](de/how-it-works.md) – was die App beantwortet,
   was auf der Karte liegt – Straßen, Reiseziele, Orte und Touren – und was
   sie bewusst nicht tut.
2. [Woher die Daten kommen](de/data-sources.md) – jede Quelle, was aus ihr
   übernommen wird und was von Hand eingeschätzt ist.
3. [Skalen und Status](de/scales-and-status.md) – die 1–5-Bewertungen, der
   Status je Halbmonat, die Klimagrundlage, die Reichweite und wie Orte und
   Reiseziele bewertet werden.
4. [Der Weg der Daten](de/data-journey.md) – von der Quelle über Prüfung und
   Build bis zu dem, was der Browser lädt.
5. [Glossar](de/glossary.md) – Begriffe und Abkürzungen von A bis Z.

Wer am Code arbeitet, findet die englische Entwicklerdokumentation über
[AGENTS.md](../../AGENTS.md), den Einstieg in Code und Dokumente.
